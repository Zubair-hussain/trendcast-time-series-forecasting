# TrendCast Dataset Card

## Summary
`data/trends_dataset.csv` is a **fully synthetic, original** engagement-trends
dataset generated by `trendcast/dataset.py`. No third-party data, scraped
content, or licensed corpus is used anywhere in this project. Because every
value is produced deterministically by the included generator, the dataset is
original work and is distributed under the project's MIT license.

## Provenance
- **Source:** procedurally generated (NumPy PRNG, fixed seed `20260101`).
- **Not derived from** any external dataset, API dump, or platform export.
- **Reproducible:** `python -m trendcast.dataset` regenerates it byte-for-byte.

## Schema (long format)

| column      | type   | description                                   |
|-------------|--------|-----------------------------------------------|
| `series_id` | string | topic identifier, e.g. `topic_007`            |
| `archetype` | string | `viral_spike` / `slow_burn` / `seasonal` / `fad_fade` |
| `day`       | int    | day index (0-based)                           |
| `value`     | float  | simulated daily engagement (≥ 0)              |

## Composition
- 40 series × 120 days = **4,800 rows** by default (configurable).
- Four archetypes are balanced 10 / 10 / 10 / 10.
- Each series layers a base archetype signal, weekly seasonality, a small
  random walk, and heteroscedastic noise.

## Intended use
Benchmarking short-horizon univariate trend forecasters and demoing the
momentum score. **Not** intended to represent any real platform's metrics.

## Regenerate / customise
```bash
python -m trendcast.cli gen --series 100 --length 180 --out data/my.csv
```
