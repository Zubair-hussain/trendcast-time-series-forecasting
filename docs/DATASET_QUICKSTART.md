# TrendCast — Synthetic Engagement-Trends Forecasting Dataset

A fully synthetic, **original** multi-series dataset for short-horizon
univariate trend forecasting, together with a lightweight reference model
(**TrendCast**) and reproducible baselines.

Every value is procedurally generated by the included code (`trendcast/dataset.py`,
NumPy PRNG, fixed seed `20260101`), so the data is original work with no
third-party or scraped content. Distributed under the **MIT** license.

## The dataset — [`data/trends_dataset.csv`](../data/trends_dataset.csv)

Long format, 4,800 rows: **40 series × 120 days**, four balanced trend archetypes.

| column      | type   | description                                           |
|-------------|--------|-------------------------------------------------------|
| `series_id` | string | topic identifier, e.g. `topic_007`                    |
| `archetype` | string | `viral_spike` / `slow_burn` / `seasonal` / `fad_fade` |
| `day`       | int    | day index (0-based)                                   |
| `value`     | float  | simulated daily engagement (≥ 0)                      |

Each series layers a base archetype signal, weekly seasonality, a small random
walk, and heteroscedastic noise. See [DATASET.md](DATASET.md) for the full card.

## Models included

| Model | Type | Description |
|-------|------|-------------|
| **naive** | baseline | persistence — forecast = last observed value |
| **drift** | baseline | linear extrapolation of the last 7 points |
| **TrendCast** | reference | ensemble of **Holt double-exponential smoothing** + a **Ridge regressor** on lag/rolling features (blend `w=0.3`), plus a 0–100 momentum/virality score |

## Benchmark results

Measured on the shipped dataset — 40 series, **horizon = 14**, forecasting the
held-out tail. Lower is better. Reproduce with `python benchmarks/benchmark.py`.

| Model | sMAPE % | MAE | Notes |
|-------|--------:|----:|-------|
| naive | 33.52 | 30.02 | hard-to-beat persistence baseline |
| drift | 85.81 | 52.00 | overshoots on noisy series |
| **TrendCast** | **29.24** | **19.05** | **−37% MAE vs. naive** |

> At very short horizons (h ≤ 7) naive persistence is strong on noisy data and
> TrendCast is roughly on par; TrendCast's advantage grows with the horizon,
> where level + slope modelling pays off.

## Quickstart

```python
from trendcast import TrendCast, generate_dataset

series = generate_dataset(n_series=1, length=120)[0].values
fc = TrendCast().fit(series[:-14]).forecast(horizon=14)

print(fc.label)      # "rising" | "steady" | "fading"
print(fc.momentum)   # e.g. 78.4
print(fc.point)      # 14 forecasted values
```

Full example: [`examples/quickstart.py`](../examples/quickstart.py). Requires Python 3.9+, NumPy + scikit-learn.

## Regenerate / customise

```bash
python -m trendcast.cli gen --series 100 --length 180 --out data/my.csv
```
